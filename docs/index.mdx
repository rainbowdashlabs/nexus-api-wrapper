# Nexus API Wrapper

The Nexus API Wrapper is a small Java client for the REST API of
[Sonatype Nexus Repository 3](https://help.sonatype.com/en/rest-apis.html). It covers the parts you need to find and
fetch artifacts:

- search for components and assets, with all common search parameters,
- read, list, download and delete assets,
- list repositories.

Every request can run blocking on your thread or asynchronous with a `CompletableFuture`. Requests share a rate limit,
so a loop over many pages does not flood your Nexus.

It does not cover the admin parts of the API, like creating repositories, users, roles or tasks.

## Requirements

| What | Version |
|---|---|
| Java | 21 or newer. The library is compiled for Java 21 and ships a module descriptor (`de.chojo.nexus`). |
| Nexus Repository | 3, with the REST API under `/service/rest/v1`. Checked against 3.96.1 Community. |
| Jackson | 2 (`com.fasterxml.jackson`). The library brings `jackson-databind` with it. |
| SLF4J | The library logs through `slf4j-api` and brings it. Add an SLF4J binding to see the log output. |

## Quick start

Find the newest jar of an artifact and download it:

```java
NexusRest nexus = NexusRest.defaultApi("eldonexus.de");

PageAssetXO page = nexus.v1().search().assets().search()
        .repository("maven-releases")
        .mavenGroupId("de.chojo")
        .mavenArtifactId("nexus-api-wrapper")
        .mavenExtension("jar")
        .sort(Sort.VERSION)
        .direction(Direction.DESC)
        .complete();

AssetXO newest = page.items().getFirst();
byte[] jar = newest.download().complete();
```
